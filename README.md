\# ISL Setu — Indian Sign Language Translator



ISL Setu is a two‑way Indian Sign Language (ISL) communication system that enables

real‑time conversations between deaf/mute users and hearing people.



\- \*\*Sign → Text → Speech\*\*: Recognizes ISL signs from a webcam, converts them to gloss,

&#x20; then into natural sentences in English/Hindi/Marathi and speaks them out.

\- \*\*Text → Sign\*\*: Converts typed sentences into ISL gloss and replays the signs as a

&#x20; hand‑skeleton avatar on canvas.

\- \*\*Role‑based usage\*\*: Separate flows for Doctor, Police, Teacher, and Public, with

&#x20; Spring Boot + MySQL backend for operator login, deaf/mute person details, and

&#x20; conversation history dashboard.



\## Tech stack



\- \*\*Frontend\*\*: React (Vite), MediaPipe Hand Landmarker, WebSocket, HTML/CSS

\- \*\*Core backend\*\*: Python, FastAPI, PyTorch, MediaPipe, Groq LLM

\- \*\*Auth / storage backend\*\*: Java, Spring Boot, MySQL

\- \*\*Other tools\*\*: Git/GitHub, Postman, mkcert, Spring STS
